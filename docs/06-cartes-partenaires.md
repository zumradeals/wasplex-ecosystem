# Cartes partenaires Wasplex

## 1. Objectif

Les cartes partenaires donnent à un utilisateur accès à des avantages, offres et opérations proposées par Wasplex avec des partenaires vérifiés.

Une carte peut être virtuelle et, si l’offre le prévoit, disposer d’un support physique facultatif.

La carte n’est pas une action de société, une part du capital, une cryptomonnaie ou une garantie de rendement.

## 2. Référence de l’ancien produit

L’ancien dépôt présentait plusieurs paliers de cartes configurables avec :

- nom ;
- prix ;
- durée ;
- statut actif ;
- renouvellement ;
- historique de revenus ;
- pourcentage de redistribution configurable ;
- distribution périodique.

Il utilisait le terme « micro actionnaire » et une redistribution provenant des achats de nouvelles cartes. Ce modèle ne doit pas être repris automatiquement.

La nouvelle direction est celle de **cartes partenaires** : la valeur redistribuable doit provenir d’opérations économiques externes et réelles avec les partenaires, pas du recrutement permanent de nouveaux acheteurs de cartes.

## 3. Types de cartes

L’administration peut créer plusieurs offres de cartes.

Chaque offre doit pouvoir définir :

- nom affiché ;
- code interne ;
- description ;
- prix ;
- devise ;
- durée ;
- renouvellement ;
- support virtuel ou physique ;
- coût du support physique ;
- conditions d’éligibilité ;
- services inclus ;
- partenaires et catégories d’offres accessibles ;
- plafonds ;
- dates d’effet ;
- état actif ou inactif ;
- visuel et ordre d’affichage.

Les noms et paliers ne doivent pas être codés en dur.

## 4. Partenaires

Un partenaire doit posséder un dossier vérifié comprenant selon le risque :

- identité légale ;
- représentant ;
- coordonnées professionnelles ;
- pays et zones d’activité ;
- offre ou service proposé ;
- méthode de vérification des opérations ;
- taux ou montant de commission ;
- calendrier de règlement ;
- conditions de remboursement ;
- contrat et dates de validité ;
- statut actif, suspendu ou terminé.

Un partenaire ne reçoit pas un accès général aux données Wasplex.

## 5. Offres partenaires

Une offre peut proposer :

- réduction immédiate ;
- cashback ;
- avantage en nature ;
- tarif préférentiel ;
- accès prioritaire ;
- service inclus ;
- points ou WasPoints financés ;
- autre bénéfice validé.

Chaque offre doit afficher :

- partenaire ;
- avantage ;
- conditions ;
- lieux ou canaux ;
- dates ;
- plafonds ;
- exclusions ;
- preuve attendue ;
- délai de validation.

## 6. Opération partenaire

Le cycle attendu est :

1. l’utilisateur présente ou utilise sa carte ;
2. le partenaire enregistre l’opération ;
3. Wasplex reçoit une référence vérifiable ;
4. l’opération est confirmée ;
5. la commission ou l’avantage est calculé ;
6. le partenaire règle la somme due ;
7. la valeur devient distribuable ;
8. le gain éventuel est crédité au Wallet ;
9. l’utilisateur et le partenaire voient le résultat ;
10. les remboursements ou annulations produisent une correction traçable.

Aucun gain ne doit être crédité uniquement sur la déclaration non vérifiée d’un utilisateur ou d’un partenaire.

## 7. Sources de valeur

Les gains liés aux cartes doivent provenir de sources externes identifiables, par exemple :

- commission sur une vente réelle ;
- remise financée par le partenaire ;
- budget promotionnel ;
- frais de service réellement encaissés ;
- autre revenu contractuel lié à une opération.

Le prix payé pour acheter ou renouveler une carte rémunère d’abord les services de la carte. Il ne doit pas servir automatiquement à payer les détenteurs antérieurs.

## 8. Formes possibles de partage

Une opération partenaire peut combiner :

- un avantage direct pour l’utilisateur ayant réalisé l’opération ;
- une part Wasplex ;
- un éventuel pool collectif de détenteurs éligibles ;
- une part destinée au partenaire ou à un coût externe.

La formule exacte doit être configurée et annoncée avant l’opération.

Le système doit conserver :

- montant brut de l’opération ;
- commission externe ;
- frais et taxes ;
- montant net partageable ;
- avantage direct ;
- part Wasplex ;
- part collective éventuelle ;
- règle et version appliquées.

## 9. Pool collectif éventuel

Si Wasplex décide d’un pool collectif, il doit être alimenté uniquement par des revenus externes validés.

L’administration doit définir :

- opérations contributrices ;
- pourcentage affecté ;
- cartes éligibles ;
- période ;
- formule de répartition ;
- date de calcul ;
- minimum de distribution ;
- traitement du reliquat ;
- annulations ;
- rapport public agrégé.

Une période sans revenu peut produire une distribution nulle. Aucun minimum n’est garanti.

## 10. Cycle de vie d’une carte

États possibles :

- commandée ;
- paiement en attente ;
- active ;
- support physique en préparation ;
- expédiée ;
- suspendue ;
- expirée ;
- renouvelée ;
- fermée ;
- remboursée.

L’expiration de la carte ne supprime pas les gains déjà validés.

## 11. Application utilisateur

L’espace Cartes doit permettre de :

- consulter les offres ;
- comparer les cartes ;
- acheter ou renouveler ;
- afficher la carte virtuelle ;
- demander un support physique ;
- consulter les partenaires ;
- consulter les avantages ;
- voir les opérations ;
- voir les gains et leur origine ;
- signaler une opération manquante ;
- suspendre une carte perdue ;
- consulter les conditions.

## 12. Espace partenaire

Le partenaire doit pouvoir :

- gérer ses points de vente ;
- publier des offres soumises à validation ;
- enregistrer ou confirmer une opération ;
- consulter les commissions dues ;
- charger des preuves ;
- traiter une annulation ou un remboursement ;
- consulter des statistiques agrégées ;
- gérer ses représentants autorisés.

## 13. Administration

L’administration doit permettre :

- création des cartes ;
- gestion des prix et durées ;
- vérification des partenaires ;
- gestion des contrats ;
- publication des offres ;
- configuration des commissions ;
- validation des opérations ;
- rapprochement des règlements ;
- distribution des avantages ;
- gestion du support physique ;
- suspension et clôture ;
- historique et audit.

## 14. Décisions ouvertes

- premiers types de cartes ;
- prix et durées ;
- avantages de chaque carte ;
- formule de commission ;
- présence ou non d’un pool collectif ;
- formule de partage du pool ;
- règles du support physique ;
- partenaires pilotes ;
- calendrier de règlement ;
- traitement des remboursements et litiges.
