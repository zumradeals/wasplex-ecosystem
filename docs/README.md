# Documentation métier Wasplex

Ces fichiers expliquent directement ce que Wasplex doit faire. Ils servent de référence aux humains et aux agents de développement.

## Documents actifs

- `00-vision-generale-wasplex.md` — rôle de la plateforme et articulation des modules ;
- `01-modele-economique-publicitaire.md` — annonceurs, ciblage, prix, Feed, partage de valeur ;
- `02-abonnements-et-types-utilisateurs.md` — abonnements, trois types économiques et quotas ;
- `03-wallet-et-waspoint.md` — valeur, soldes et mouvements ;
- `04-fonds-social.md` — adhésion, vœux, apports, réserve et réalisation ;
- `05-alertes-et-protection.md` — objets, documents, véhicules, personnes, SOS et diffusion ;
- `06-cartes-partenaires.md` — cartes, partenaires, avantages et revenus externes.

## Utilisation

Chaque document distingue :

- ce qui est décidé ;
- ce qui doit être configurable ;
- le parcours attendu ;
- ce qui reste à décider ;
- les erreurs à éviter.

Lorsqu’une décision change, le document métier concerné est mis à jour directement. Il n’est pas nécessaire de créer une loi, un amendement ou un nouvel acte interne.
