# Alertes et protection

## 1. Objectif

Le module Alertes permet de déclarer, diffuser, rapprocher et clôturer des situations nécessitant l’attention de la communauté, de Wasplex ou d’une institution habilitée.

Il couvre notamment :

- objets perdus ou trouvés ;
- documents perdus ou trouvés ;
- véhicules volés ou retrouvés ;
- adultes disparus ou retrouvés ;
- enfants disparus ou retrouvés ;
- SOS et urgences ;
- alertes institutionnelles ou nationales lorsque des intégrations réelles existent.

Le module doit privilégier la protection des personnes, la vérité des statuts et la limitation des données exposées.

## 2. Référence de l’ancien produit

L’ancien dépôt comportait déjà :

- un choix de catégories publiques ;
- des formulaires spécifiques selon objet, document, véhicule ou personne ;
- lieu, date, photo et description ;
- masquage public des numéros de documents ;
- confidentialité renforcée pour les mineurs ;
- récompense optionnelle ;
- dossiers en attente de validation ;
- rapprochement entre une déclaration de perte et une déclaration de découverte.

Ces fonctions constituent une base utile. Les anciennes règles de paiement et de publication doivent être vérifiées avant reprise.

## 3. Types de dossiers

### Objets et documents

Le déclarant peut indiquer :

- type ;
- marque ;
- couleur ;
- signes distinctifs ;
- lieu et date ;
- photos ;
- numéro de document complet dans une zone privée ;
- version masquée visible publiquement.

### Véhicules

Le dossier peut contenir :

- type de véhicule ;
- marque et modèle ;
- couleur ;
- année ;
- plaque ;
- numéro de châssis ;
- photos ;
- lieu et circonstances.

Les identifiants complets sensibles ne doivent pas tous être rendus publics.

### Personnes disparues ou retrouvées

Le dossier peut contenir :

- nom lorsque sa publication est légitime ;
- tranche d’âge ;
- sexe ;
- description physique ;
- vêtements ;
- signes distinctifs ;
- dernier lieu connu ;
- photo autorisée ;
- contact ou institution responsable du dossier.

Les enfants et personnes vulnérables nécessitent une visibilité plus contrôlée et une validation renforcée.

### SOS et urgence

Un SOS doit permettre une action rapide avec le minimum de saisie :

- nature du danger ;
- localisation disponible ;
- moyen de rappel ;
- informations vitales strictement nécessaires ;
- état de transmission.

Wasplex ne doit jamais afficher « secours en route » ou « institution prévenue » sans preuve réelle.

## 4. Création d’une alerte

Le parcours attendu :

1. choix de la catégorie ;
2. formulaire adapté ;
3. contrôle des informations sensibles ;
4. ajout des preuves et photos ;
5. choix de visibilité ;
6. paiement éventuel uniquement pour les catégories où il est justifié ;
7. soumission ;
8. modération ou validation ;
9. publication et diffusion ;
10. mises à jour ;
11. correspondance éventuelle ;
12. clôture.

Une erreur de saisie doit pouvoir être corrigée sans perdre tout le dossier.

## 5. Visibilité et confidentialité

Les niveaux de visibilité peuvent être :

- public ;
- communauté limitée ;
- zone géographique ;
- institution seulement ;
- restreint au personnel Wasplex ;
- privé au déclarant et aux responsables du dossier.

La page publique ne doit pas exposer inutilement :

- numéro complet de document ;
- adresse précise du domicile ;
- numéro personnel sans consentement ;
- données médicales ;
- identité d’un mineur au-delà du nécessaire ;
- informations pouvant mettre une victime en danger.

## 6. Diffusion

La diffusion dépend du type d’alerte :

- Feed Wasplex ;
- notifications dans une zone ;
- partage public contrôlé ;
- transmission à une institution ;
- interruption prioritaire du contenu pour une alerte critique réellement autorisée.

La portée, la durée et la fréquence sont configurables.

Une alerte nationale ou institutionnelle n’est activée que si l’émetteur et le canal sont réellement intégrés et habilités. Wasplex ne doit pas simuler une capacité qu’il ne possède pas.

## 7. Correspondances

Wasplex doit pouvoir rapprocher :

- objet perdu et objet trouvé ;
- document perdu et document trouvé ;
- véhicule volé et véhicule retrouvé ;
- personne disparue et signalement correspondant.

Une correspondance automatique reste une proposition à confirmer. Elle ne clôture pas seule un dossier.

Le processus attendu :

1. détection ou signalement d’une correspondance ;
2. comparaison des éléments protégés ;
3. contact contrôlé ;
4. vérification de propriété ou d’identité ;
5. restitution ou mise en sécurité ;
6. confirmation par les parties autorisées ;
7. clôture et preuve.

## 8. Récompenses

Une récompense peut être proposée pour certains biens ou véhicules, à condition qu’elle soit préfinancée et que ses conditions soient claires.

Aucune récompense ne doit servir à acheter la localisation ou la remise d’une personne disparue, d’un enfant, d’une victime ou d’un SOS.

Pour un objet ou véhicule :

- montant ;
- conditions ;
- fonds réservés ;
- preuve de restitution ;
- délai de contestation ;
- paiement au bénéficiaire ;
- remboursement si la récompense n’est pas due.

## 9. Institutions

Une institution habilitée peut :

- recevoir un dossier correspondant à sa mission ;
- accepter ou refuser la prise en charge ;
- demander des informations ;
- mettre à jour un statut ;
- confirmer une action ;
- clôturer sa participation.

L’institution ne reçoit que les informations nécessaires au dossier.

Les statuts doivent rester littéraux :

- transmis ;
- reçu ;
- consulté ;
- accepté ;
- en traitement ;
- action réalisée ;
- clôturé ;
- refusé ;
- sans réponse.

## 10. Modération et sécurité

Wasplex doit vérifier :

- fausses déclarations ;
- contenu diffamatoire ;
- usurpation ;
- exposition dangereuse de données ;
- publication de mineurs ;
- tentative d’extorsion ;
- fausse récompense ;
- images choquantes ;
- doublons ;
- détournement publicitaire.

Le retrait public d’une alerte ne supprime pas automatiquement l’historique nécessaire au traitement, à la sécurité ou à une contestation.

## 11. Administration

L’administration doit permettre :

- gestion des catégories ;
- prix éventuels de publication ;
- gratuité des catégories essentielles ;
- durées et rayons de diffusion ;
- modération ;
- protection des mineurs ;
- gestion des correspondances ;
- transmission institutionnelle ;
- récompenses et remboursements ;
- statistiques agrégées ;
- audit des changements de statut.

## 12. Décisions ouvertes

- catégories gratuites et payantes ;
- catégories pouvant porter une récompense ;
- rayons et durées par catégorie ;
- conditions exactes de publication immédiate ou après validation ;
- partenaires institutionnels par pays ;
- canaux externes de diffusion ;
- durée de conservation des données ;
- règles de contact entre déclarant et personne ayant trouvé.
