# Fonds social Wasplex

## 1. Objectif

Le Fonds social aide des utilisateurs à réaliser un besoin ou un projet concret appelé « vœu » grâce à une organisation collective, un apport personnel, une réserve dédiée et un traitement contrôlé par Wasplex.

Le Fonds social est séparé :

- des budgets publicitaires ;
- des abonnements publicitaires ;
- du Wallet ordinaire ;
- des revenus partenaires ;
- de la trésorerie courante de Wasplex.

Une adhésion donne accès au mécanisme. Elle ne garantit pas qu’un vœu sera financé ni une date certaine de réalisation.

## 2. Référence de l’ancien produit

L’ancien dépôt contenait déjà des idées fonctionnelles utiles :

- plans annuels séparés du niveau publicitaire ;
- nom, prix, plafond de vœu, pourcentage d’apport et nombre maximal de vœux configurables ;
- catégories comme transport, immobilier, santé, éducation et activité professionnelle ;
- suivi de l’apport ;
- date de déblocage estimée ;
- états du dossier ;
- réserve communautaire ;
- traitement spécial des urgences.

Ces éléments servent de base de compréhension. Les anciennes valeurs, noms de plans et formules ne sont pas repris automatiquement.

## 3. Plans du Fonds social

Wasplex doit pouvoir créer plusieurs plans administrables.

Chaque plan peut définir :

- nom affiché ;
- code interne ;
- description ;
- prix d’adhésion ;
- durée de l’adhésion ;
- montant maximal d’un vœu ;
- pourcentage minimal d’apport personnel ;
- nombre maximal de vœux actifs ;
- catégories autorisées ;
- délai minimum avant éligibilité ;
- règles d’urgence ;
- pays et devise ;
- dates d’effet ;
- état actif ou inactif.

Le Fonds social ne doit pas être automatiquement lié au type économique publicitaire. L’administration peut proposer des avantages compatibles, mais les deux mécanismes restent comptablement séparés.

## 4. Catégories de vœux

Les catégories peuvent notamment couvrir :

- transport : voiture, moto, tricycle, taxi, camion ;
- logement : terrain, maison, construction, rénovation ;
- santé : opération, hospitalisation, équipement ou assurance ;
- éducation : frais scolaires, université, formation ;
- activité professionnelle : commerce, matériel, équipement ;
- autre besoin accepté par Wasplex.

Les catégories, sous-catégories et justificatifs sont configurables depuis l’administration.

## 5. Déclaration d’un vœu

L’utilisateur renseigne au minimum :

- catégorie ;
- titre et description ;
- montant estimé ;
- fournisseur ou prestataire lorsqu’il est connu ;
- justificatifs ;
- urgence éventuelle ;
- apport personnel disponible ;
- délai souhaité ;
- consentements nécessaires.

Le système calcule une première estimation selon le plan actif, mais ne promet pas la réalisation avant examen.

## 6. Vérification du dossier

Wasplex vérifie :

- identité selon le niveau de risque ;
- ancienneté et statut de l’adhésion ;
- conformité du vœu ;
- réalité du besoin ;
- cohérence du montant ;
- fournisseur ou devis ;
- apport personnel ;
- absence de doublon ;
- disponibilité des ressources ;
- urgence et vulnérabilité lorsqu’elles sont pertinentes.

Une insuffisance de moyens ou un retard de contribution ne doit pas être automatiquement qualifié de fraude.

## 7. Apport personnel

Le plan peut exiger un pourcentage d’apport.

L’apport peut être :

- versé en une fois ;
- constitué progressivement ;
- payé directement au fournisseur ;
- exceptionnellement réduit pour une urgence grave validée.

L’apport reste rattaché au dossier. Sa destination en cas d’annulation doit être expliquée avant paiement.

## 8. Financement collectif et réserve

Le Fonds peut recevoir des ressources provenant de mécanismes autorisés, par exemple :

- adhésions ;
- contributions volontaires ;
- affectations propres de Wasplex ;
- partenaires ou donateurs ;
- autres sources externes acceptées.

Chaque source reste traçable.

La réserve communautaire indique :

- période ;
- montants reçus ;
- montants affectés ;
- montants engagés ;
- montants payés ;
- reliquat ;
- nombre de dossiers aidés.

La transparence porte sur les fonds et les résultats agrégés, pas sur l’exposition publique des difficultés privées des bénéficiaires.

## 9. Sélection et priorité

La priorité ne dépend pas uniquement du plan payé.

Le traitement peut tenir compte de :

- urgence vitale ou grave ;
- vulnérabilité ;
- impact social ou professionnel ;
- ancienneté du dossier ;
- niveau d’apport atteint ;
- ressources disponibles ;
- faisabilité ;
- qualité des justificatifs.

Une urgence grave validée peut passer avant un projet non urgent, même lorsque le demandeur urgent possède un plan moins élevé.

## 10. Réalisation du vœu

Wasplex privilégie la réalisation concrète :

- paiement direct au fournisseur ;
- achat ou livraison du bien ;
- règlement de l’établissement ;
- contrôle de la prestation ;
- preuve de réception.

Le versement libre d’espèces au bénéficiaire n’est pas le fonctionnement normal. Toute exception doit être justifiée, plafonnée et traçable.

## 11. États du dossier

Le parcours peut utiliser des états simples :

- brouillon ;
- soumis ;
- vérification en cours ;
- informations complémentaires demandées ;
- éligible ;
- en constitution d’apport ;
- en attente de ressources ;
- planifié ;
- en réalisation ;
- réalisé ;
- refusé ;
- annulé ;
- contesté ;
- clôturé.

Chaque état doit expliquer à l’utilisateur ce qui s’est passé et la prochaine action possible.

## 12. Annulation et reliquats

La règle commerciale doit préciser :

- remboursement ou non de l’adhésion ;
- remboursement de l’apport non engagé ;
- traitement des frais externes ;
- traitement d’une commande déjà passée ;
- destination des reliquats ;
- procédure de contestation.

Aucun solde ne doit être absorbé silencieusement.

## 13. Administration

L’administration doit permettre :

- gestion des plans ;
- gestion des catégories et pièces demandées ;
- examen des adhésions et dossiers ;
- suivi de l’apport ;
- gestion de la réserve ;
- validation des fournisseurs ;
- planification des paiements ;
- preuve de réalisation ;
- annulation et remboursement ;
- rapports agrégés ;
- historique complet des décisions.

## 14. Décisions ouvertes

- source et formule exacte des contributions collectives ;
- calendrier de sélection ;
- règles précises de priorité ;
- durée minimale d’adhésion ;
- calendrier d’apport ;
- traitement d’un retard ;
- règle de remboursement de l’adhésion ;
- cas autorisant un paiement monétaire direct ;
- formule de la réserve et éventuels frais Wasplex.
