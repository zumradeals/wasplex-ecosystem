# Assets de marque Wasplex

Déposer ici les fichiers officiels de la marque (DS-0001 §3/§4) :

| Fichier attendu | Usage |
| --- | --- |
| `wasplex-logo.png` | Logo complet (martin-pêcheur + wordmark) — écrans d'accueil et d'authentification |
| `wasplex-mascot.png` | Mascotte seule (oiseau) — en-têtes compacts, Feed |
| `wasplex-logo.svg` / `wasplex-mascot.svg` | Variantes vectorielles si disponibles (préférées) |

Tant que ces fichiers sont absents, l'interface utilise la vectorisation
directionnelle `resources/js/components/wasplex-mascot.tsx`. Dès qu'un
fichier officiel est déposé et versionné, les composants basculent dessus
(remplacement, jamais les deux à la fois).
